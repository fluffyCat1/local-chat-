# Local Chat (NeoForge 1.21.1)
Обычное сообщение - локальный чат (радиус 100 блоков). Сообщение с `!` в начале - глобальный чат.
Настройки: config/localchat-common.toml. Мод нужен только на сервере.

Сборка через GitHub: залей файлы в репозиторий -> вкладка Actions -> Build mod -> Artifacts -> localchat-mod.
